# AD 007 Retire the Java dorkbox cleanup shim

Status: accepted by the user on 2026-10-17. Omit `dorkboxupdater` from BiglyBTC's
native migration and native release catalogue. Do not create a native repository,
binary, installer or replacement download for this obsolete cleanup behavior.

Inspected original repository:
https://github.com/BiglySoftware/BiglyBT-plugin-dorkboxupdater.git
at `83da70fdac15cf9f0f1372e25956c28a88c39f51`, source
`src/com/biglybt/plugin/DorkBoxUpdaterPlugin.java`.
The plugin checks for `dorkbox-systemtray.jar` in the Java install directory,
stages a move to `.obsolete` when an SWT UI attaches, and offers a Java client
restart. This is installation cleanup, not native tray functionality.

The accepted retirement applies to that cleanup behavior. Native Linux tray
support remains a platform/UI requirement with its own qualification. The Java
`azupdater` replacement is a different component and remains required.

Preserve the original source reference, installed Java JARs, plugin descriptors,
configuration keys and unknown plugin data. Native discovery may recognise the
original ID as retired, but must not execute its cleanup, rename/delete its
files, reset its shared enabled setting or try to download a native counterpart.
The running original application is never stopped or asked to restart.

This is an accepted scope decision, not a claim of a ported implementation or
qualified native tray. Source inspection was read-only; no plugin was launched
and no live profile or Java installation was modified. There is no behavioral
implementation to test in this documentation change. Future discovery/catalogue
tests must cover the retired disposition without altering shared Java artifacts.
