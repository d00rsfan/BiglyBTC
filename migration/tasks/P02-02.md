# P02 bounded executor and cancellation contracts

- Phase P02; F28, F29, F30; state implemented (uncommitted); owner/integrator Codex.
- Decision: AD-003; source baseline
  `cb8c6cb9bb97916cbc7e80338a017200ffc3e71f`, AsyncDispatcher/AEThread2 and
  plugin lifecycle contracts. This is a foundation, not complete host API parity.
- Inputs: pinned C++23 runtime pair, isolated native build/test harness.
- Writes: native core/tests and migration records; no profiles/network/install.

Implement explicit startup, one owned worker, a bounded queue, move-only commands,
typed outcomes/futures, cooperative cancellation and drain-on-shutdown. Reject
overload and stopped/unstarted submissions explicitly. Complete every accepted
future exactly once; do not invoke stop callbacks under the queue mutex.

Verify FIFO execution, cancellation before/during dispatch, shutdown with pending
work, move-only capture lifetimes, exception outcomes, callback reentry and
concurrent producers on both compilers. Run ASan/UBSan/LSan and qualify TSan
separately. Implementation remains uncommitted; complete command/query/event and
capability APIs remain later P02 work.

Both compiler suites and Clang ASan/UBSan/LSan and TSan passed the bounded
executor contract. Logs are in `migration/evidence/P02-02/`; host/service and
plugin integration remain open. No native commit hashes or full phase closure.
