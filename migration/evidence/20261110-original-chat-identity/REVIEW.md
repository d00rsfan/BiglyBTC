# Original Java chat identity compatibility

Favourite rooms loaded, but opening them could fail with “Ambiguous or unreadable
chat identity”. Original CryptoECCUtils serialises EC public points uncompressed
(49 bytes). The Native signer already validates that format, but the identity
fingerprint guard required 25-byte compressed keys. Managed-room owner parsing
had the same restriction.

Both saved formats are now accepted without rewriting their encoding or UID.
Fingerprints bind the exact UID/public/private bytes and lengths. Managed owner
keys retain SEC1 prefix checks. The unchanged signer still validates the curve,
point and public/private pair. Unreadable/invalid saved keys remain refused and
are never silently regenerated.

A new regression exports only the ephemeral identity generated by the actual
fenced original MsgSyncHandler using original CryptoECCUtils. It failed before
the fix at profile identity restoration, then passed after. It checks unchanged
config bytes/UID/public encoding, source fingerprint, signed room exchange,
history reopening, 49-byte managed owner inheritance, read-only guest refusal,
owner message verification and corrupt private-scalar refusal without rewriting
the configuration. No user key or actual application profile enters the test.

Four focused suites passed in 2.52 seconds: full original Java handler,
asynchronous profile, managed/nickname policy, and original general-chat profile.
Existing Java/Native message exchange and 25-byte Native key cases remain
covered. Original handler/core and Native signer sources are unchanged. The
fenced test adapter exposes its generated identity only; no sockets, personal
files or live chat posts are used. No fresh sanitizer result is claimed.

The separate chat-preview executable was atomically replaced; exact launcher
inputs passed. The running user process, protected daily-use candidate and SDK
provider remain unchanged. User restart/real-room acceptance is still pending.

Per the user's request, this round fixes only chat identity. Waiting with no
