Recommend one useful manager milestone: an explicitly owned I2CP session can
carry concurrent independent byte streams and accept a verified incoming peer.
Four live streams and four pending SYNs are proposed native envelopes, not Java
defaults. This removes the next structural limit after the window change without
claiming a complete torrent backend.

Proposed scope after explicit approval

Add a bounded manager to InitialChannel over the existing pure Connection actor:
explicit connect/listen/accept/read/write/half-close/cancel by nonreused operation
ID; signed inbound SYN creates an inbound-role Connection only after exact full
Destination/recipient/port verification. Keep current1024 lifetime ID exclusion
and explicit exhaustion initially, rather than weakening qualified stale-ID
behavior. Hold no application bytes outside four64KiB TX+RX envelopes; add a
global bound and fair packet turn across streams while retaining one bounded
I2CP socket frame. Preserve datagram2/3, RAW18 tracker, fetch/End and queue bounds.

Established connections use source-compatible activity/idle decisions; handshake
and each explicit application wait retain finite deadlines. Retained signer,
current generation/session/acknowledged policy/unexpired actual LS2 remain gates
before every read/write/send. Session loss or source retirement withdraws all
streams before queued callbacks. One-stream cancel or EOF must leave others
usable. Lease renewal may preserve connections only under the same retained
identity/session and actual renewed lease; no submitted-LS2 equals OPEN claim.

Acceptance is one actual manager vertical: two concurrent outbound HTTP streams
plus a Java-initiated native inbound BitTorrent handshake over the same I2CP
session; distinct bytes/IDs, signed SYN refusal, bounded flood/pressure, one-stream
cancel, peer reset and late/reused IDs. Reuse the real b086 manager adapter and
its exact routing fence. One separate actual active>120s case can prove that
traffic plus genuine lease renewal survives the former total budget; pure clock
controls cover idle actions. A real isolated-router case exercises concurrent
both-direction exchange. Preserve prior five manager controls and upload digest;
measure fairness/queues, make no throughput or public-tunnel claim.

Full-backend seams still open: profile key import/default Host ownership, address

and incoming torrent routing. network_policy.cpp519-522/532 still disables SAM
