Source and acceptance hashes are recorded in verification.json and its referenced receipts. This review covers the bounded, explicit service paths below. Both components remain in progress.

Maintenance follows the pinned original router timer: one real ten-second turn, greatest-failure contact selection, six-turn selective seed refresh, and the original 120-second subtree age exclusion. Pure controls cover the five-minute idle and clock-rollback policy; no five-minute runtime wait or public DHT coverage is claimed. The original wrapped signed comparator and TreeMap insertion order are retained for contact export.

Contact files use the original raw big-endian records, not bencode. The profile worker owns the same source gate for reads, current-source validation, compare-and-save, recovery and fsync. Primary files take precedence; saving recovery requires an absent primary. Foreign or ambiguous bytes remain unwritable. Imports supply Known contacts only; real wire exchanges establish liveness and seeding. This adapter currently supports nonnegative networks; signed-negative paths remain open. Explicit flush is acknowledged before shutdown. Blocked kernel IO can still delay the external lifetime join.

Normal packet preflights share the existing eight IO slots and 64 held-frame budget. Excess frames wait in a fixed queue for actual worker progress, preserving their original deadlines and current-source checks. Consumed commits await release without being incorrectly checked against already-completed command state. A worker Running notification reports queue progress before source access; it grants no profile permit.

Enc4 is an explicit ECIES_X25519 lease-key selection. Destination encryption identity, key files and hashes retain the existing Enc0 format. LS2 carries one type4/32-byte public key; CreateLeaseSet2 carries its corresponding private key with strict forward parsing, pair verification, renewal reuse and secret erasure. Generic absent selection remains Enc0. Existing OpenSSL and provider dependencies are unchanged.
