BiglyBTC — private I2P application preview

This preview connects the ordinary classic desktop to the separately qualified
private I2P provider. It is an explicit development mode. Public discovery,
remote/multihop qualification and full azneti2phelper compatibility are unfinished.

Run from this folder with an existing ISOLATED original-compatible profile and
an owned external router's numeric loopback I2CP port:
  ./BiglyBTC --profile /absolute/isolated/profile --private-i2p 7654

The program acquires the original exclusive profile lock. Never copy a live
Java profile while it is being written. This preview has no implicit profile
argument and never opens ~/.biglybt by itself.

The original plugin enable configuration and private saved pure destination key
plugins/azneti2phelper/dest_key1.dat must already exist. Add plain metainfo through
Open Torrent File, or use an existing I2P-only saved torrent with Tracker permission.
No identity is generated or silently substituted. The endpoint override does not
rewrite Java settings.

My Torrents (Ctrl+1) offers Start, Pause, Resume and Stop. Statistics (Ctrl+5)
contains a separate I2P tab with actual observed payload, peers and tracker
results. Unknown measurements display an em dash. Successful stop checkpoints
original progress only after real paused/flush/removal/join fences. An incomplete
checkpoint retains the original recheck marker and displays its error.

One active I2P torrent per profile; this explicit mode does not start the Public
engine. Stop the torrent before changing configuration/files. Public/mixed
network torrents and pending magnets are unsupported here. Ordinary public
BiglyBTC remains a separate existing preview until this provider is qualified
for that route. Closing the desktop waits for the real I2P owner and source.

Qt and runtime dependencies are bundled. No system install or .deb is needed.
Source, build/acceptance receipts and remaining work are recorded in migration.

The ordinary Open Torrent File dialog imports as I2P-only in this mode. Start now, Stopped and Paused are available; supported start choices survive file-preview loading. Existing saved Public/mixed torrents are not reclassified. Import journals persist the explicit network choice. Whole queue/rate policy parity remains open.
