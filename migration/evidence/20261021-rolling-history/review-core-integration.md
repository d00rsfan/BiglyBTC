2. **The real-worker fixture had a minute-boundary race.** Two consecutive reconstructed minute observations made the second “future” record become eligible if the clock advanced across the minute during asynchronous open/read, invalidating the fixed payload4/one-observation expectation. Root now inserts a separate positive `s` anchor1440minutes ahead before the second delta. The first current-minute record remains actual, the second remains beyond the bounded test operation. The unchanged-value assertions are meaningful and no accounting/production algorithm was tuned to expected output.

This does not claim immunity to arbitrary wall-clock jumps; core arithmetic uses only the explicitly supplied timestamp.
