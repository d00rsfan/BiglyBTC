This is a passive source/matching/event model prerequisite for the outstanding
tracker-property owner and transient internal tag source. It is not a running
automatic tag service, tracker request or enabled membership writer. No normal
Store configuration/effect policy is broadened in this milestone. The normal
constraint worker still withholds unowned automatic tracker facts.

An isolated JDK17 helper executes actual private getAugmentedHosts,handleProperty,
handleDownload and sync/torrentChanged bodies, actual TorrentUtils host extraction
and actual UDP/WSS URL handlers. Torrent/DownloadManager/global manager/property
boundaries are supplied inert proxies; tag membership/effects are recorded in a
real set. No Core/client, socket,DNS,filesystem payload or tracker is started.
2112 generated URL/property/event/prior-member cases are retained. Each Native
case compares parsed host/explicit/default port, augmented host set, resulting
membership and exact Add/Remove/Keep trace to that actual original result.

Original host extraction lowercases with Locale.US, adds host and positive
explicit/default-port host, then generates every dot suffix except the first
label. Trailing empty split components are discarded, interior empties retained.
Ports are part of those strings, including suffix matching. HTTP defaults80,
HTTPS443 and the actual original UDP handler defaults80; WSS has no default.
IPv6 retains brackets and textual compression. Property names are lowercased
without trimming. The Native ASCII subset preserves this spelling rather than
normalising hosts, IPs, whitespace or effective port into another value.

The qualified parser covers the generated http/https/udp/wss cases, empty
host/no-authority forms, user info, IPv4, bracketed plain hexadecimal IPv6,
explicit0,plus/zero-padded/default ports and Java int port limits. Original URL
serialises an empty authority as http:/path; the first focused case exposed that
spelling and the parser was corrected before final acceptance. Unknown Unicode
case/URI forms, zones, embedded-IPv4 IPv6 and other protocols remain unsupported.
No full java.net.URL replacement claim is made. Plain IPv6 group syntax is
validated; malformed inputs cannot supply a fabricated known negative match.

Startup registers the property without reconciling membership. A real created
DownloadManager only adds matches. A changed property adds/removes. Announce sync
processes properties with entries; an empty property array does not remove all
members on sync, while an actual property-clear event can. A one-entry empty
string remains distinct from no entries. The core projection is data only and
cannot supply the actual event or bypass future owning source/CAS obligations.

Endpoints,properties,text,host suffix count and combined bytes have checked
finite limits. Custom limits can only tighten the defaults. No truncated host
list becomes false; unknown data remains unavailable even after an earlier
positive witness. Tests cover unsupported types, malformed addresses/ports,
no trimming, interior/trailing labels and small/excess limits.
